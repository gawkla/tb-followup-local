# Contributing

Bug reports and focused pull requests are welcome.

- Include your Thunderbird version, operating system, steps to reproduce, and expected/actual behavior.
- Test changes on a dedicated Thunderbird profile with nonessential messages.
- Keep changes small and avoid altering existing storage keys without a migration strategy.
- Run the included Node.js tests before submitting a pull request.
- Do not include real email messages, message subjects, personal folder paths, profile logs, or credentials in issues or commits.
- Contributions are intended to be distributed under the repository's Mozilla Public License 2.0.
