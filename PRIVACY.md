# Follow-up Local — Privacy Policy

Follow-up Local is designed to run locally within Mozilla Thunderbird.

## Information processed

To track conversations and match replies, the extension accesses local message metadata such as subjects, senders, recipients, Message-ID headers, In-Reply-To and References headers, folder locations, message identifiers, and message tags. It reads message information as needed to detect replies, locate originals, and generate local reminder messages.

## Stored on your device

Thunderbird extension storage holds follow-up task records, deadlines, status changes, relevant message identifiers, folder references, preferences, and diagnostic entries. Generated reminder messages are imported into Thunderbird Local Folders.

## Message actions

On the user's request and according to the configured settings, the add-on may add/remove follow-up tags, optionally move an original message to Local Folders Inbox when a reminder is due, and create a locally imported reminder linked to the original conversation. These reminders are **not sent over SMTP**.

## No automatic external transmission

Follow-up Local does not contain an analytics service, advertising tracker, external processing backend, or automated upload of emails or task records. It does not send email content, follow-up metadata, or diagnostic logs to the developer.

## Optional donations

An optional Ko-fi link (`https://ko-fi.com/gawkla`) appears in the add-on interface. Ko-fi is not contacted automatically. If a user clicks it, their browser opens a third-party website subject to its own privacy practices. Donating is entirely optional.

## User control

Users can reschedule and finish tasks and clear finished records within the extension. The add-on's stored data is part of the user's local Thunderbird profile. Users should follow Thunderbird's profile and add-on data management procedures when deleting it; uninstalling the add-on does not remove the underlying email messages.

**Scope:** Thunderbird Local Folders only; no IMAP or POP folder monitoring.
