# Changelog

## 0.1.26 — Reschedule existing follow-ups

- Detect an already active follow-up when the same message is selected, and offer to update the existing deadline.
- Add **Reschedule** to active task rows in the queue.
- Rescheduling an already reminded task returns it to Waiting and preserves its record and reply monitoring.
- Previously generated local reminders remain; updating does not immediately create a duplicate.
- Public/ATN build ID: `gawkla.followup-local@addons.thunderbird.net`.

## 0.1.25

- Reuse/focus the existing Follow-up window rather than opening multiple windows.

## 0.1.24

- Make the Log panel toggle open/closed with repeated clicks.

## 0.1.23

- Clear the Finished task list after confirmation.
- Move optional Ko-fi support from the bottom of the queue into the interface settings area.

## 0.1.20–0.1.22

- Overdue toolbar warning, English interface and optional Ko-fi link.

## Earlier releases
